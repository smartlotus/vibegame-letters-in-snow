# 流年 · 雪中信 (letters-in-snow)

改编自同名小说《流年》（正文首行《异乡人》）的**叙事视觉小说 + 轻探索**游戏。
Phaser 3 (CE) + vibegame 引擎；文本层全部走 DOM UI，Phaser 只负责"世界"。

```bash
vibegame run games/letters-in-snow            # 启动（headless 加 --headless）
vibegame check games/letters-in-snow          # 静态检查
```

## 一句话

> 他需要靠近，她需要远离。
> 当一根弦被绷到最紧的极致时，要么断裂，要么触底反弹。

## 核心机制

| 机制 | 说明 |
|---|---|
| **「弦」张力** | 全篇唯一的数值，屏幕顶端一条会随张力拉直、颤动、泛红的弦。**伸手和退开都在把弦拉紧** —— 小说那句原文直接变成了机制 |
| **双身同弦** | 玩家在忒斯章节与她章节之间交替扮演，两边的选择推动同一根弦。不是让你选边，是让你承认两边都没有错 |
| **断裂 / 触底反弹** | 弦到临界时按玩家的伸手/退开比例分流：偏伸手 → 弦绷断（白闪、锐响、世界更冷）；偏退开 → 弦回弹（暖光） |
| **「留印」** | 26 枚可收集的句子（被划掉的、说出口又反悔的、只在心里说过的）。**跨周目累积**——部分留印只存在于某一条分支上 |
| **五行信** | 第五章是可交互小游戏：从 12 个句子里**恰好选出 5 行**才能寄出 |
| **七日独处** | 第七章是七天逐日推进的序列，配一条「完整感」进度 |
| **十字架的归还** | 终局开放选择，两个结局分支 |

## 结构

```
scripts/
  Director.js    剧本执行器：章节游标、弦、留印、存读档、终局、测试钩子
  StoryData.js   全九章剧本（607 节点）+ 26 枚留印
  VnUi.js        DOM 界面层：对话框/选项/弦/章节卡/信件/七日/回忆录/统计
  VnStyle.js     整套 UI 样式（作为 JS 模块随 scripts/ 一起发布）
  Stage.js       Phaser 世界层：背景交叉淡入、氛围色、震动、信纸黑边
  Walker.js      四向行走（4 方向动画、雪地脚印、热点浮标）
tools/
  build_assets.py     69 张源资产表 → 抠底/切帧/重排 → assets/ + manifest.json
  verify_assets.py    资源完整性校验
  optimize_preload.py 背景转 JPEG + 道具清单拆出主清单（48.9MB → 8.2MB）
  audit_story.mjs     剧本静态审计：留印可达性 / 选项完整性 / 资源键存在性
```
